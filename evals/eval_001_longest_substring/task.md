# Task: Longest Substring Without Repeating Characters

Source: [LeetCode 3](https://leetcode.com/problems/longest-substring-without-repeating-characters/)

Given a string `s`, return the length of the longest substring that contains
no repeated characters.

| Input        | Output | Why            |
| ------------ | ------ | -------------- |
| `"abcabcbb"` | 3      | `"abc"`        |
| `"bbbbb"`    | 1      | `"b"`          |
| `"pwwkew"`   | 3      | `"wke"`        |

Constraints: `0 <= len(s) <= 5 * 10^4`; `s` contains English letters, digits,
symbols and spaces.
